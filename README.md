HOW TO PREVIEW LOCALLY
----------------------
Double-click "home.html". It will open in your browser. Click around — nav links,
"Book" buttons, Services tabs — to make sure everything works the way you expect.


HOW TO DEPLOY (free, ~5 minutes)
--------------------------------
The simplest path is Netlify. No technical setup needed.

1. Go to https://app.netlify.com/drop
2. Drag this entire folder onto the page.
3. Netlify will give you a live URL within seconds, like
   https://ambitious-edge-1234.netlify.app
4. Inside Netlify, you can connect your own domain (ambitionedge.com etc.)
   under Site Settings → Domain management.

That's it. Your website is live.
